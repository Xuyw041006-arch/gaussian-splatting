# Semantic v5：语言、层级亲和与重要性自适应 3DGS

本文描述当前源码中的 v5 实验方案，不是已训练完成或已达到 SOTA 的声明。
v3 已有真实 GPU 测量；它不能证明 v5 改动有效。v5 必须使用独立场景监督、
独立输出目录和同协议基线完成评估，不能把旧权重直接改名为 v5。

本文的默认值指 `scripts/run_ramen_benchmark.py --semantic_protocol v5` 的
Ramen 配置，而不是所有入口的默认值。直接执行 `train.py --semantic_protocol v5`
仍需显式传入预热、三级权重等参数；仅切换协议名不会自动应用整套基准配置。

## 1. 为什么改为两种特征

“两个不同实例”和“两个不同语义类别”不是同一件事。例如两根筷子可能具有
相同的语言含义，却需要在交互选取时分开。v5 不再让同一组 CLIP 特征既拟合
文本含义，又被实例对比损失强迫相互远离。

| 字段 | 默认维数 | 学习目标 | 导出和查询方式 |
|---|---:|---|---|
| 语言特征 | 32 | SAM 区域 CLIP 描述子的训练集 PCA 表示 | `features[N,32]` 经 sigmoid 后存储；查询前反变换回可重构 CLIP 空间 |
| 层级亲和特征 | 16 | SAM 区域之间同组/异组关系 | `affinity_features[N,16]` 保留有正负的向量；8/12/16 维前缀对应粗/中/细 |
| 重要性 | 每高斯 1 个分数 | 背景、普通、重要三级资源分配 | `importance_score`；小于 0.25 为背景，0.25 至小于 0.75 为普通，至少 0.75 为重要 |

两组特征在实现中存放于同一个参数张量的不同通道，随高斯 clone/split/prune
保持对齐，但没有共享语义损失。亲和分支按 8/4/4 维残差组分别 L2 归一化；
查询时取前缀并再整体归一化，不对亲和分支执行 PCA、min/max 解码或 sigmoid。
语言工件不再导出旧 `scale_gate`。源码：
[联合监督器](../semantic/joint_trainer.py)、[v5 损失](../semantic/v5.py)、
[查询与数值工具](../semantic/artifact.py)。

重要边界：默认 `semantic_geometry_grad=False`。RGB 损失继续更新位置、尺度、
旋转、不透明度与颜色；语义损失默认只更新语言/亲和字段，以免不可靠二维伪标签
直接拉坏几何。重要性仍通过 RGB 加权、分裂/剪枝阈值和 SH 容量间接影响重建。
这属于同一训练流程中的多分支学习，不等于默认让所有语义损失反传到几何。
`train.py --semantic_geometry_grad` 是独立消融选项；开启时分子特征渲染和
alpha 分母均参与梯度，不能仅对分母断梯度。

## 2. 论文借鉴范围

| 参考方法 | 本版已实现的借鉴 | 尚未实现或不能声称等价的部分 |
|---|---|---|
| 原始 3D Gaussian Splatting | 保留可微高斯渲染、RGB 优化、clone/split/prune；重要性调节原始致密化阈值 | 没有新增五阶 SH CUDA 内核；不能把较多高斯直接当成较好精度 |
| LangSplat / LERF | 区域 CLIP 蒸馏；还原 PCA 可重构 CLIP 空间；目标与通用负词的相关度评分 | 不是 LangSplat 的自编码器、多套语言场和完整评测后处理复现 |
| SAGA | 语言与实例亲和目标分离；同组/异组对比；点提示亲和检索 | 没有 SAGA 的物理 3D 尺度估计、尺度分位数条件或连续尺度门控；本版只有二维包含层级 |
| LaGa | 独立亲和字段、残差分组的粗到细表达；可选训练后多视角区域描述符对齐库 | 尚无官方式明确对象分解、per-object adaptive K-means 与完整对象级描述符聚合复现 |
| Gaussian Grouping | 增加与官方 LERF-Mask 最终 mask 几何规则一致的 `gg_native` 计分选项 | 没有完整复现其实例身份场、Grounded-SAM 到 3D 实例的查询训练流程 |

对应官方依据：
[原始 3DGS](https://github.com/graphdeco-inria/gaussian-splatting)、
[LangSplat 评分实现](https://github.com/minghanqin/LangSplat/blob/main/eval/openclip_encoder.py)、
[SAGA 训练实现](https://github.com/Jumpat/SegAnyGAussians/blob/v2/train_contrastive_feature.py)、
[LaGa 官方实现](https://github.com/SJTU-DeepVisionLab/LaGa)、
[Gaussian Grouping 评估实现](https://github.com/lkeab/gaussian-grouping/blob/main/script/eval_lerf_mask.py)。
这是有选择的工程借鉴，不是上述论文的集合复现，也不保证超过这些方法。

## 3. 二维教师、层级和词汇选择

Ramen v5 基准使用 SAM ViT-H 与 OpenCLIP `ViT-H-14 / laion2b_s32b_b79k`。
默认 SAM 网格边长 32、裁剪金字塔 1 层、最多保留 192 个区域、语义图宽 512。
候选采用大小兼顾的保留方式，而非只取最大区域。CLIP 裁剪由完整 mask 包围盒
得到，背景置白并补成正方形，避免标准中心裁剪截去细长物体两端。

语言教师使用原始区域 CLIP 的 PCA 表示；v5 预处理明确 `prototype_mode=off`，
训练关闭旧全局原型牵引、语言实例负对比和旧语言门控。即使兼容元数据中仍有
原型数组，也不能据此声称进行了 LaGa 的对象级多描述子融合。

三层区域来自二维 mask 包含关系，不是仅按面积把区域分箱。亲和训练遵循：
细层同组意味着更粗层应同组；粗层异组意味着更细层应异组。非嵌套 SAM 输出
造成冲突的样本对会忽略；未知区域 ID 不作为负样本。默认每 4 步采样最多
320 个像素，正/负 cosine margin 为 0.8/0.2，组范数正则系数 0.05。

跨视角约束的当前范围：所有相机共同优化同一组 3D 特征，可产生共享一致性；
但 v5 没有显式跨视角对象追踪、遮挡感知对应或官方 LaGa 对象库，因此不能声称
已经解决跨视角实例一致性。二维教师不可靠的部分仍可能互相冲突。下述训练后
区域对齐库是独立可选检索分支，不改变这一训练范围。

词汇与重要性流程支持候选词表匹配生成 `scene_inventory.json`，再由用户或 LLM
确认背景/普通/重要。SAM 只给 mask，CLIP 只在候选文本中匹配，不会自动发现
任意未知物体名称。Ramen 基准为固定可复现比较使用：

- 重要：`egg, pork belly, wavy noodles in bowl`。
- 普通：`yellow bowl, chopsticks, glass of water`。
- 背景：显式候选 `table, wall`；不是把所有未知区域都归为背景，也没有完整人工背景标注。

v5 使用 `competitive_v1`：要求目标 CLIP cosine 至少 0.25、相对通用负词的
相关度至少 0.60、相对于其他档位候选的优势至少 0.04；重要区域面积比例须
小于 0.80，防止一张覆盖整个餐桌的 mask 被标为重要物品。不确定区域保留普通
档且 `importance_known=False`，不强制为每个提示词分配区域。旧模式的 0.24
阈值不是当前 v5 决策规则。这些是固定初值，不是已证明最优的超参数；应先检查
词汇和区域预览，不能看测试 IoU 后重新分档包装结果。SAM 置信度只是 mask
质量，不是语义分类的可信概率。

高斯的重要性采用升降对称的 EMA（动量 0.9）；未知像素不更新既有分数。
与旧版“只要有一次高重要性观察立即上调”不同，不因单视角误匹配永久升档。
这仍不包含遮挡感知的显式跨视角对应，不能视作已解决所有投影冲突。
教师实现见 [preprocess_semantics.py](../preprocess_semantics.py)。

## 4. 15k 配置：预热、损失和高斯预算

训练上限默认 15,000 次迭代，不是每次都保证运行满 15,000 次，也不是每轮
遍历全部图片。预热区间为迭代 `<2500` 的纯 RGB；从 2500 开始引入语义。
语义损失系数经过 2,000 步余弦 ramp，到 4500 达到完整强度。重要性 RGB 加权、
容量分配在 2500 开启；它们不是同一个连续 ramp。预热长度是可调超参数，
目前 2500 是预设值，不是已经自动搜索出的最优值。

| 设置 | 背景 | 普通 | 重要 |
|---|---:|---:|---:|
| RGB L1 档位权重 | 0.75 | 1.0 | 2.0 |
| 语义像素档位权重 | 0.5 | 1.0 | 2.0 |
| 分裂/克隆梯度阈值倍率 | 1.15 | 0.8 | 0.5 |
| 不透明度剪枝阈值倍率 | 1.0 | 0.7 | 0.35 |
| 有效 SH 最高阶 | 1 | 2 | 3 |

基础致密化梯度阈值为 `1e-4`，所以三个档位对应 `1.15e-4 / 8e-5 / 5e-5`；
阈值更低更容易生成高斯。基础不透明度阈值 0.005，对应
`0.005 / 0.0035 / 0.00175`，重要档更温和地剪枝。但过大屏幕/空间尺度等
原始剪枝规则仍生效，不保证重要点绝不被删除，也没有固定百万点数量保证。
从 500 之后开始每 100 步检查致密化；15k 配置的截止值为 11250，最后有效
周期通常为 11200，余下阶段精修。相关代码见
[基准入口](../scripts/run_ramen_benchmark.py)、[高斯生命周期](../scene/gaussian_model.py)。

SH 三档通过屏蔽梯度、清零超出档位的系数实现，CUDA 场景最高仍为三阶。
目前仍按场景最大阶分配参数并调用渲染器；“有效低阶容量”不等于已实现
逐高斯可变长度存储或按档位节省同等比例的 kernel 运算量。

语言 L1 基础系数 0.12，语义学习率 0.005；边界梯度对齐系数 0.06。
每步通常渲染 3 个三通道块；每 8 步完整渲染 32 维，并计算系数 0.1 的
可重构 CLIP cosine 损失，最多采样 2048 个有效像素。亲和损失系数 0.05。
周期损失乘对应周期长度，以保持其期望权重；这些不是每步都完整计算的损失。
验证使用固定全部语言通道和确定性采样，不采用训练期随机亲和采样。

语义像素权重包含 SAM 置信度、三级档位、细节权重和受限逆区域面积权重。
面积平衡为 `(中位区域面积/本区域面积)^0.5`，裁剪到 `[1/8,8]`，避免大碗
压过细筷子，也避免单像素噪声无限放大。训练语义覆盖要求 alpha 至少 0.05。
RGB 保留原始 L1/DSSIM 混合，DSSIM 默认 0.2；三级权重直接作用于 L1。

## 5. 边界和细长物体保护的实际含义

默认边界带宽 3 个语义图像素、边界增强 2.25、细长区域增强 1.50；细长度
结合紧致度阈值 0.40 和包围盒长宽比阈值 2.5。v5 的 `competitive_v1` 将边界
和物品语义分档解耦：边界与细长区域只提高 `detail_weight`，不再自动提升
`importance` 档位。细节权重直接参与语义损失；不能声称每条边界都获得了
更高 RGB/致密化档位。重要性容量仍由有足够文本证据的分档控制。

此外对预测和教师特征的局部梯度作边界对齐。它匹配的是 SAM 教师边界，
不是凭空创造真值边界；如果 SAM 漏掉筷子，单纯增加边界权重或高斯数量仍
不能恢复可靠语义。512 宽的监督图也不是无限分辨率，必须检查实际叠加图。

## 6. 固定数据划分与不可混用的实验

本 Ramen 实验目标为 **119 个训练视角、12 个验证视角、3 个有人工 mask 的
测试视角**。这是从 131 个非测试视角中选 12 个验证视角得到的划分；数据中
实际另有共 4 个 RGB 测试视角。第 4 个无对应此表人工 mask 的视角只进入
独立的 `all_test_rgb`，不能用于替补 annotated 三视角的 PSNR/SSIM。
实际运行必须核对相机名和计数，不能仅凭目录里文件数宣称满足划分。

PCA、编码范围和候选统计只在 119 个训练视角拟合。12 个验证视角可运行固定
预训练 SAM/CLIP 做变换，但不参加上述拟合，也不进入优化器训练视角。
测试视角仅在最后做推理和评价。保留提供的 COLMAP 相机/初始点云这一共同条件；
没有重新验证 SfM 是否严格只用训练图片，不宣称完整 SfM 层面的独立数据协议。

| 实验 | 可以回答的问题 | 不能混称的结果 |
|---|---|---|
| 旧 v3 + 旧评分 | 历史可复查基线，已测 mIoU 19.2962% | 含旧训练/监督局限，不是同配置 v5 对照 |
| 同一 v3 + 新评分 | PCA cosine、像素合成和 mask 计分协议影响 | 没训练新模型；分数变化不能说是训练提升 |
| 固定二维教师文本查询 | SAM 候选、CLIP 检索、PCA 压缩各自损失 | 不是 novel-view 3D 分割 |
| 二维 SAM oracle | 利用 GT 选择最佳单个候选，检查候选能否覆盖目标 | 使用了 GT；不是可部署性能，也不是全方法理论上限 |
| 新 v5 从头训练 | 新监督、分离字段、边界与资源分配的综合效果 | 需要完成后才能报数；不能继承 v3 训练时间为零 |
| 新顺序基线 | 均匀 RGB 训练后冻结几何，再蒸馏同一个教师的语言特征 | 没有 v5 亲和分支，不是所有损失逐项相同的消融 |

v5 与新顺序基线共享数据、二维教师、相机、评价分辨率和最终文本评分。
顺序 RGB 用统一权重、SH3；随后 `train_semantics.py` 固定几何，以学习率
0.005 和空间正则 0.02 蒸馏语言特征。该对照用于比较整体流程；若要证明
某个损失有效，还须另外做同架构去掉该项的消融。

v5 基准默认评价为 `clip_relevancy`，负词
`object / things / stuff / texture`，温度 10、阈值 0.5，`gg_native`：预测
mask 最近邻对齐原始 GT、边界比例 0.02、边缘补零、先类别平均再宏平均。
固定 middle 参数 1；v5 语言是单一字段，没有旧 scale gate，因此它不等价于
自动挑选最有利的三个语言层。亲和三级点查询是单独的交互能力。

旧协议仍为 `legacy_pca_cosine / legacy / 0.25 / granularity=1 / boundary=0.008`。
两种协议分别存储，禁止自动算“新减旧提升”。2D 教师诊断当前边界计分又使用
0.008 且不补边缘，必须独立列示，不能直接对比 v5 的 gg_native Boundary-IoU。
细节见 [评分审查报告](../reports/semantic_scoring_review_2026-09-09.md)。

验证集选最佳权重，以 RGB PSNR 为准；每 1000 步检查一次，15k 配置从第 6000
步开始实际检查，早停耐心为 4 次。更优权重即保存；0.02 dB 仅用于早停耐心。
目录 `iteration_15000` 可能是最佳验证导出的别名，要读取
`validation_summary.json` 和 `weight_selection`，不能把它误报为末轮模型。
没有人工验证 mask 时，验证教师误差不是人工 mIoU，不应伪称在语义真值上选优。

默认先跑联合模型，再以它的记录用时给顺序 RGB+语义分配预算。只有三阶段
完整累计时长齐全、均完成，且总时差在显式容差 `max(5秒,联合用时×2%)` 内，
才能认证等时间。预处理、评估与传输不包含在训练预算内，应另列开销。中断后
历史时长不全、只能估计文件时间、或顺序 RGB 已超预算，都不能宣称等时间。

## 7. 启动、恢复与验收

使用只包含数据和相机、未混入旧语义文件的独立场景目录。完整基准入口示意：

```bash
python -m scripts.run_ramen_benchmark \
  --scene /content/ramen_v5_scene --sam_checkpoint /content/sam_vit_h_4b8939.pth \
  --output_root /content/ramen_v5_15k/outputs_full \
  --semantic_protocol v5 --iterations 15000 \
  --semantic_start 2500 --semantic_ramp_iterations 2000
```

`--prepare_only` 只准备教师，不训练；`--resume` 只用于同一 v5 实验恢复。
基准入口生成 `sparse/0/train.txt`、`val.txt`、`test.txt`，仍需核对它们与
运行日志中真正使用的相机一致。冻结参考包含 PCA、编码边界、元数据和数据
划分指纹；`v5_teacher_files.json` 进一步逐个记录语义 map 和重要性 PNG 的大小和 SHA-256。
复用时检查训练/验证名称、教师版本、包含层级、`prototype_mode=off`、全部
map 的维数和宽度，不是只检查某一个文件是否存在。

不能在保留旧参数的同时重新生成不同 mask 并声称仍是同一个完整教师。RGB
重要性还会读取 `importance_masks/*.png`，它也必须与对应 map 保持一致；
不能单独改 PNG 后继续旧训练。发现参考不一致时应停止恢复，保留旧模型，
修正独立实验配置后再训练，而不是覆盖已有结果。

最终交付应包含：双方实际训练计数/用时/选权重来源、相同协议下的 PSNR、
SSIM、mIoU、Boundary-IoU、逐类别和三级统计、高斯数量、GT/渲染并排图、
人工/预测 mask 叠加图、语义字段与相机配置。当前没有完整背景人工 mask，
背景 IoU 应记未测；不能用 `1−前景IoU` 推算。

重点检查筷子、蛋、猪肉、面条：先看 SAM oracle，再看固定 CLIP 检索，再看
3D 渲染是否退化。这样才能区分候选漏检、语言不匹配和跨视角蒸馏错误。多随机
种子和单项消融仍是后续工作；新模型、稀疏视角、单图补全和 UI 端到端表现
都不能由这份实现说明代替实测。

## 8. 可选：训练后多视角、多粒度区域描述符对齐库

新入口为 [build_semantic_descriptor_bank.py](../scripts/build_semantic_descriptor_bank.py)，
共享纯数值评分在 [descriptor_bank.py](../semantic/descriptor_bank.py)。这是借鉴
LaGa 的工程小版本：保留多个原始区域 CLIP 描述子，不将所有视角平均成单个
语言向量；通过已经训练的独立亲和字段对齐区域与高斯。它不是 LaGa 官方的
对象级自适应 K-means 聚类，没有生成经过验证的永久对象身份。

构库严格使用训练名单与 PCA `fit_image_names` 一致的相机，只打开选定训练
图片和缓存，不读取验证/测试 RGB 或人工 mask。默认均匀选择 24 个训练视角，
每图按层级和 SAM 置信度轮转保留至多 96 个区域、每区域采样至多 512 个有效
像素；总记录硬上限 8192。每个区域可保存多个层级记录，因此实际默认上限为
24×96×3=6912 条。采样参数、视角名、缓存 SHA、模型与亲和 SHA 均写入库。

每张图以不截断正负值的方式渲染 16 维亲和特征并除以 alpha，按缓存中的
原始重叠 SAM mask 池化，不使用会吞掉小物体的独占 region map。区域必须在
相应粗/中/细层出现，才建立该层记录。每条记录保留原始完整 CLIP 描述子、
独立亲和向量、视角、区域 ID、层级、SAM 置信度、有效覆盖率和亲和一致度。
默认过滤 alpha<0.05 的像素、覆盖率<0.35 或池化一致度<0.10 的区域。
构库校验当前 v5 的 `competitive_v1 / containment / prototype_mode=off`
教师，并核对工件中的 PCA/编码参数；重要性策略指纹被记录，但重要/普通
标签不参与候选排名，避免人为提示词权重直接抬高检索分数。

检索分为两步：先以固定正负词相关度（默认≥0.5）筛选语言候选，再仅用同层
亲和 cosine（默认≥0.8）确认至少两个不同训练视角支持；CLIP 相似度不能充当
几何对应。每次保留至多 64 条候选，按视角轮转，防止同图大量重叠 mask 占满。
高斯与候选匹配阈值为亲和 cosine≥0.7；至少两个不同视角匹配后才输出非零分。
最终分数为 `max(文本相关度×SAM置信度×覆盖率×亲和一致度)`，默认选择阈值
0.25。不同视角/层级的原始描述子仍在库中，没有被全局平均。这些值是事先固定
的工程初值，不是通过测试 GT 挑选的最佳参数。

```bash
# 要先有真正包含独立亲和字段的 v5 导出；已有输出文件不会被覆盖。
python -m scripts.build_semantic_descriptor_bank \
  --model /content/ramen_v5_15k/outputs_full/joint --iteration 15000 \
  --output /content/ramen_v5_region_bank.npz

python semantic_query.py --model /content/ramen_v5_15k/outputs_full/joint \
  --iteration 15000 --text "chopsticks" --granularity 1 \
  --descriptor_bank /content/ramen_v5_region_bank.npz --threshold 0.25 \
  --output /content/chopsticks_bank_selection.npz

# 独立输出目录；只在建库完成后评测，不能与旧评分自动相减。
python -m scripts.evaluate_lerf_mask \
  --model /content/ramen_v5_15k/outputs_full/joint --iteration 15000 \
  --test_mask /content/ramen_v5_scene/test_mask \
  --descriptor_bank /content/ramen_v5_region_bank.npz \
  --mask_protocol gg_native --threshold 0.25 --granularity 1 \
  --boundary_ratio 0.02 --output /content/ramen_v5_eval_region_bank
```

该分支记录为独立的 `descriptor_bank` 评分，不能把其阈值 0.25 等同于旧 PCA
cosine 0.25。评测器可调用同一个 `score_descriptor_bank`，对高斯或渲染后的
alpha 归一亲和像素评分；调用者先核验模型签名，并保持其他 mask 协议一致。
缺少亲和字段、模型顺序/几何不匹配、训练名单混入 held-out、库不存在有效区域
时明确报错；无多视角支持的查询返回空，不强制 top-k。

本地 11 项测试覆盖重叠区域保留、跨视角而非同图重复计数、同层支持、文本相同
但亲和不同的拒绝、分块一致性、模型签名和采样限制；其中带正负值的渲染调用
测试使用轻量数值替身，不是 CUDA 性能或质量测试。短至 300 步的 smoke 导出
即使能够构库，也只能验证流程，不能证明亲和已学好或分割有所提升。真实质量
还须新 v5 完整训练后在固定 annotated 测试集按独立协议测量，并额外报告构库
时间、库大小和检索时间；不能隐去这一后处理成本。
