# Joint Semantic-Adaptive 3DGS

本模型把 RGB 重建、层级语义蒸馏和三级重要性资源分配放进同一次 3DGS
优化。它借鉴 LaGa 的跨视图语义聚合思想，以及 SAGA 的尺度门控和多粒度分割
思想，但当前实现是面向一周 MVP 的工程化组合，不是两者的官方复现。

本文描述 2026-09-09 修正后的代码。最高 SH 阶数为 3、三级容量为 `1/2/3`；
v4 尚未完成 GPU 训练与对照评估。代码修复不能代替质量指标，详见
[本次证据审计](../reports/ramen_audit_2026-09-09.md)。

## 1. 数据流

```text
多视角图像 + COLMAP 相机
           │
           ├─ SAM 多尺度区域 ─ CLIP ViT-H/14 区域描述符
           │                      │
RAM++ 提议词汇 ─ SAM+CLIP 验证    ├─ 训练视角 96 原型聚合（跨视图监督）
用户/LLM 三级词表                 │
重要 / 普通 / 背景 ───────────────┤
                                  ├─ PCA 32 维层级语义监督
                                  ├─ 每视图三级重要性图
                                  └─ 边界 + 细长物体 detail 权重
                                                │
原始 3DGS RGB loss ─────────────────────────────┤
层级 semantic loss ─────────────────────────────┼─ 同一次 backward
3D 邻域 consistency loss ───────────────────────┤
                                                │
                         重要性控制 split / prune / SH capacity
```

每个高斯除原始位置、协方差、透明度和球谐颜色外，还带有 32 维语义参数
`s_i` 和 `[0,1]` 重要性分数 `q_i`。clone、split、prune 会同步复制或过滤
这两个字段，因此不存在“重建完以后再硬贴语义”的断层。

## 2. 跨视图与多粒度监督

对 SAM 区域 `r`，先计算置信度：

```text
c_r = max(0.05, sqrt(predicted_iou_r * stability_r))
```

仅用训练视角区域 CLIP 特征拟合最多 96 个原型。区域到所属原型的融合权重为：

```text
beta_r = 0.72 * clip(cos(f_r, p_k) * compactness_k * c_r, 0, 1)
f'_r   = normalize((1 - beta_r) * f_r + beta_r * p_k)
```

这用于抑制单视图 SAM/CLIP 抖动，实际收益仍需评估。每个像素还保存 prototype id；联合训练加入
显式 prototype loss，使不同视角的渲染特征收敛到同一场景原型。它仍不是
LaGa 完整的相机重投影对象图，几何遮挡关系仍由 3D Gaussian 渲染间接处理。
聚合后的特征以训练视角拟合的 PCA 压到 32 维，编码上下界也只由训练区域决定。
Ramen 的 12 张验证图通过 `--fit_exclude_list` 排除出原型、PCA、编码上下界和
词汇排名的拟合；验证图仅使用冻结后的变换。旧版 131 图共同拟合属于
transductive 预处理，不能直接称为完全独立的语义验证。

SAM 区域按占图面积分三层，并额外保留 region id 用于 SAGA 式区域对比：

- fine：`area < 5%`
- middle：`5% <= area < 25%`
- coarse：`area >= 25%`

训练按 coarse → middle → fine 循环，并通过由尺度输入控制的 sigmoid channel
gate 选择语义通道。每轮渲染 3 个 RGB chunk，即监督 9 个语义维度；chunk
轮换覆盖全部 32 维。渲染结果除以 alpha，避免透明背景把特征幅值压小。

## 3. 三级重要性

区域与用户或 LLM 文本做 CLIP 匹配；相似度阈值为 `0.24`，默认保留所有达到
阈值的区域。可选 top-k 只限制达标结果的数量，不会强行选中低分或不存在的物体。
占图超过 `80%` 的大区域不能自动成为普通物体。重要匹配
覆盖普通匹配；未匹配区域作为背景。高斯中心投影到每轮相机后读取三级标签：

- `q < 0.25`：背景
- `0.25 <= q < 0.75`：普通
- `q >= 0.75`：重要

新出现的更高等级证据立即生效；降级证据用 `EMA=0.90` 慢速融合，以免一个
遮挡或错误视角立刻取消用户指定物体的优先级。

高斯中心的 NDC→像素变换已与 CUDA `ndc2Pix` 对齐，修正了旧实现额外翻转
图像 Y 方向的问题。旧模型的三级统计可能受此影响；更新代码不能纠正已经训练
进入旧权重的分配，需要在隔离的 v4 目录重新预处理和训练。

## 4. RGB warm-up 与联合损失

训练不是从第 1 轮就把语义施加到几何。`semantic_start` 之前使用完全未加权的
RGB L1/SSIM，重要性也不控制 split、prune 或 SH。之后在
`semantic_ramp_iterations` 内使用余弦曲线从 0 平滑升到 1；均衡档默认
`start=1500, ramp=2500`，用于减弱早期 SAM/CLIP 噪声对几何的影响。

Ramen 配置的总损失为：

```text
L = 0.8 * weighted_L1_rgb
  + 0.2 * (1 - SSIM)
  + ramp(t) * (
      0.22 * weighted_L1_semantic
    + 0.08 * L_cross_view_prototype
    + 0.08 * L_boundary_alignment
    + 0.05 * L_region_contrastive
    + 0.012 * L_edge_aware_3D_neighbor)
```

其中 RGB 像素权重和语义像素权重分别为：

| 档位 | RGB | semantic |
|---|---:|---:|
| 背景 | 0.30 | 0.12 |
| 普通 | 1.20 | 1.25 |
| 重要 | 5.00 | 5.00 |

语义误差还乘 SAM 置信度及 detail 权重。detail 权重由 3 像素边界带（boost
2.25）和细长分数（boost 1.50）构成；细长分数综合掩码紧致度与长宽比。
`L_boundary_alignment` 直接匹配渲染语义特征与 SAM 目标在水平/垂直方向的
梯度，边界像素的损失再乘 3；`L_region_contrastive` 每 4 轮按重要性采样 320
个像素，使同一 SAM region 的 cosine 高于 0.75、不同 region 低于 0.50。
`L_edge_aware_3D_neighbor` 每 8 轮在 768 个按重要性采样的高斯上计算最近邻
Smooth-L1，同时按 3D 距离、语义 affinity 与重要性档位一致性衰减，防止跨
物体边界传播。Ramen 基准默认第 1,000 轮开启语义；v4 恢复任务显式设为
1,500 轮，语义参数学习率均为 `0.01`。验证时固定 middle 粒度、覆盖所有语义
通道，并关闭随机区域/邻域采样；这些语义损失仍是伪标签指标，不能替代 mIoU。

## 5. 资源分配

原始 3DGS 的 clone/split 逻辑保留，只改变不同档位的触发阈值；基础位置梯度
阈值为 `1.0e-4`，基础 opacity 剪枝阈值为 `0.005`：

| 档位 | split 梯度阈值 | opacity 剪枝阈值 | 有效 SH 阶数 |
|---|---:|---:|---:|
| 背景 | `1.25e-4` | `0.00625` | 1 |
| 普通 | `7.20e-5` | `0.00350` | 2 |
| 重要 | `3.50e-5` | `0.00125` | 3 |

语义渲染产生的屏幕空间梯度也累计进 densification，所以语义边界可以触发
分裂。均衡/精度档把分裂窗口延长到总训练的 80%，并保留重要区域的低 opacity
高斯。SH 通过逐高斯梯度 mask 和参数归零控制容量。随仓库提供的 CUDA
前向/反向实际只计算到三阶；旧配置填写五阶只分配了额外参数，并没有启用
四、五阶渲染。新训练因此统一限制到三阶。当前仍未实现按阶数分桶的稀疏
SH kernel，不能仅凭分档配置宣称加速；需测量真实用时、峰值显存和画质。

## 6. Ramen 测试协议与结论

`scripts/run_ramen_benchmark.py` 的旧 pilot 使用 131 张训练图、4 张测试相机，
其中 3 张带 LERF-Mask 标注的测试视图用于语义和局部画质统计。固定文本阈值
0.25，不在测试标注上调参。pilot 使用 NVIDIA L4、1,500 次 RGB 迭代；顺序
基线另做 300 次语义迭代，联合模型从第 500 轮开始同时训练语义。

旧版结果保存在 `benchmarks/ramen_pilot_1500.json`。这次 pilot 中联合模型的
高斯少 44.5%，重要类别 mIoU 从 10.49% 变为 12.21%；内部重要性标签对应的
高斯占 44.58%，重要监督像素占 22.89%。这些统计不能证明高斯在真实重要物体
上的空间分配正确，旧版投影方向问题尤其需要排除。另一方面，全局 PSNR
下降 0.99 dB、全局 mIoU 下降 1.16 个百分点、Boundary-IoU 下降 3.21 个百分点。
这只能作为一次短训练的记录，不足以证明稳定提升或超过现有方法；文件里的旧
`interpretation` 是历史解释，应结合本次审计重新阅读，不作为 v4 结论。

新版代码需要重新跑基准后才可宣称语义提升；本仓库不会把代码层测试当作新的
mIoU 结果。Ramen 基准训练上限 15,000，分裂截止 11,250；通用均衡产品预设的
分裂截止为 12,000，不应混写。131 张源训练图中均匀抽取 12 张验证图，其余
119 张用于优化；预处理拟合也按上述方式排除验证图。达到验证起始轮次后每
1,000 轮验证，连续 4 次没有超过耐心参考值至少 0.02 dB 可早停。
任意更高的验证 PSNR 都会保存最佳权重，`min_delta` 只影响早停计数。

联合模型先运行并记录时长；顺序基线有同一 15k RGB 上限，尝试使用剩余时间
训练语义（等时间模式最多 15k 语义步）。只有三个阶段完成、累计时长完整且
差值在明确容差内，`protocol.equal_wall_clock` 才能认证。断点前时间不明时
必须标记不能认证；请求相同预算不代表实测用时相同。

`test_psnr` / `test_ssim` 仅统计 3 个人工标注视角；训练日志可能统计全部
4 个测试视角，两者不得直接相减。评估器记录实际相机、尺寸、标注指纹、阈值、
粒度与 `boundary_ratio`；权重选择来源区分最佳 checkpoint 与末轮/导出别名。
`--all_test_rgb` 可另外报告全部测试相机，保留独立口径。v4 仍待 GPU 实测。

## 8. 下一轮优先优化

1. 用相机位姿和深度重投影构造显式对象轨迹，替代当前原型 id 的弱匹配。
2. 在验证集上加入语义 proxy 指标，而不只用 RGB PSNR 选择最优轮次。
3. 加入 prompt ensemble，并在不读取测试标注的前提下校准文本阈值。
4. 为不同 SH 阶数实现分桶 rasterization，才能把“有效阶数”真正转成运行时收益。
