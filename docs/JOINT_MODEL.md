# Joint Semantic-Adaptive 3DGS

本模型把 RGB 重建、层级语义蒸馏和三级重要性资源分配放进同一次 3DGS
优化。它借鉴 LaGa 的跨视图语义聚合思想，以及 SAGA 的尺度门控和多粒度分割
思想，但当前实现是面向一周 MVP 的工程化组合，不是两者的官方复现。

## 1. 数据流

```text
多视角图像 + COLMAP 相机
           │
           ├─ SAM 多尺度区域 ─ CLIP ViT-H/14 区域描述符
           │                      │
用户/LLM 三级词表                 ├─ 全场景 96 原型聚合（跨视图去噪）
重要 / 普通 / 背景 ───────────────┤
                                  ├─ PCA 32 维层级语义监督
                                  ├─ 每视图三级重要性图
                                  └─ 边界 + 细长物体 detail 权重
                                                │
原始 3DGS RGB loss ─────────────────────────────┤
层级 semantic loss ─────────────────────────────┼─ 同一次 backward
3D 邻域 consistency loss ───────────────────────┤
                                                │
                         重要性控制 split / prune / SH capacity
```

每个高斯除原始位置、协方差、透明度和球谐颜色外，还带有 32 维语义参数
`s_i` 和 `[0,1]` 重要性分数 `q_i`。clone、split、prune 会同步复制或过滤
这两个字段，因此不存在“重建完以后再硬贴语义”的断层。

## 2. 跨视图与多粒度监督

对 SAM 区域 `r`，先计算置信度：

```text
c_r = max(0.05, sqrt(predicted_iou_r * stability_r))
```

将全场景区域 CLIP 特征聚为最多 96 个原型。区域到所属原型的融合权重为：

```text
beta_r = 0.72 * clip(cos(f_r, p_k) * compactness_k * c_r, 0, 1)
f'_r   = normalize((1 - beta_r) * f_r + beta_r * p_k)
```

这会降低单视图 SAM/CLIP 抖动。每个像素还保存 prototype id；联合训练加入
显式 prototype loss，使不同视角的渲染特征收敛到同一场景原型。它仍不是
LaGa 完整的相机重投影对象图，几何遮挡关系仍由 3D Gaussian 渲染间接处理。
聚合后的特征以全场景 PCA 压到 32 维。

SAM 区域按占图面积分三层：

- fine：`area < 5%`
- middle：`5% <= area < 25%`
- coarse：`area >= 25%`

训练按 coarse → middle → fine 循环，并通过由尺度输入控制的 sigmoid channel
gate 选择语义通道。每轮渲染 3 个 RGB chunk，即监督 9 个语义维度；chunk
轮换覆盖全部 32 维。渲染结果除以 alpha，避免透明背景把特征幅值压小。

## 3. 三级重要性

区域与用户或 LLM 文本做 CLIP 匹配；相似度阈值为 `0.24`，并为每个提示词
保底选择 top-1 区域。占图超过 `80%` 的大区域不能自动成为普通物体。重要匹配
覆盖普通匹配；未匹配区域作为背景。高斯中心投影到每轮相机后读取三级标签：

- `q < 0.25`：背景
- `0.25 <= q < 0.75`：普通
- `q >= 0.75`：重要

新出现的更高等级证据立即生效；降级证据用 `EMA=0.90` 慢速融合，以免一个
遮挡或错误视角立刻取消用户指定物体的优先级。

## 4. 联合损失

Ramen 配置的总损失为：

```text
L = 0.8 * weighted_L1_rgb
  + 0.2 * (1 - SSIM)
  + 0.22 * weighted_L1_semantic
  + 0.06 * L_cross_view_prototype
  + 0.012 * L_edge_aware_3D_neighbor
```

其中 RGB 像素权重和语义像素权重分别为：

| 档位 | RGB | semantic |
|---|---:|---:|
| 背景 | 0.30 | 0.12 |
| 普通 | 1.20 | 1.25 |
| 重要 | 5.00 | 5.00 |

语义误差还乘 SAM 置信度及 detail 权重。detail 权重由 3 像素边界带（boost
2.25）和细长分数（boost 1.50）构成；细长分数综合掩码紧致度与长宽比。
`L_edge_aware_3D_neighbor` 每 8 轮在 768 个按重要性采样的高斯上计算最近邻
Smooth-L1，同时按 3D 距离、语义 affinity 与重要性档位一致性衰减，防止跨
物体边界传播。Ramen 从第 1,000 轮开启语义，语义参数学习率 `0.01`。

## 5. 资源分配

原始 3DGS 的 clone/split 逻辑保留，只改变不同档位的触发阈值；基础位置梯度
阈值为 `1.0e-4`，基础 opacity 剪枝阈值为 `0.005`：

| 档位 | split 梯度阈值 | opacity 剪枝阈值 | 有效 SH 阶数 |
|---|---:|---:|---:|
| 背景 | `1.25e-4` | `0.00625` | 1 |
| 普通 | `7.20e-5` | `0.00350` | 3 |
| 重要 | `3.50e-5` | `0.00125` | 5 |

语义渲染产生的屏幕空间梯度也累计进 densification，所以语义边界可以触发
分裂。SH 通过逐高斯梯度 mask 和参数归零实现不同有效阶数。当前 CUDA
rasterizer 仍按场景全局最高五阶执行，因此计算节省主要来自高斯总数减少，
不是完整的稀疏 SH kernel 加速。

## 6. Ramen 测试协议与结论

`scripts/run_ramen_benchmark.py` 的旧 pilot 使用 131 张训练图、4 张测试相机，
其中 3 张带 LERF-Mask 标注的测试视图用于语义和局部画质统计。固定文本阈值
0.25，不在测试标注上调参。pilot 使用 NVIDIA L4、1,500 次 RGB 迭代；顺序
基线另做 300 次语义迭代，联合模型从第 500 轮开始同时训练语义。

真实结果保存在 `benchmarks/ramen_pilot_1500.json`。联合模型用少 44.5% 的
高斯，使重要类别 mIoU 从 10.49% 提升到 12.21%；重要高斯占 44.58%，而
重要监督像素占 22.89%，说明优先密度分配确实发生。另一方面，全局 PSNR
下降 0.99 dB、全局 mIoU 下降 1.16 个百分点、Boundary-IoU 下降 3.21 个百分点。
因此当前证据支持“重点资源分配有效”，不支持“全局质量已经超过现有方法”。

新协议把总训练上限固定为 15,000，densification 在第 11,250 轮结束。131 张
源训练图中均匀抽取 12 张作为独立验证集，其余 119 张用于优化；每 1,000 轮
验证一次，连续 4 次提升不足
0.02 dB 就早停，最终选择验证 PSNR 最优权重。官方 `test_*` 和 `test_mask`
只用于最终报告。联合模型先运行并记录墙钟时间；顺序基线使用相同 15k RGB
上限，剩余时间用于后训练语义（最多 15k 语义步），因此总时间预算可直接比较。
`comparison.json` 同时记录实际时间、验证轨迹、最佳轮次和早停状态。

## 7. 下一轮优先优化

1. 用相机位姿和深度重投影构造显式对象轨迹，替代当前原型 id 的弱匹配。
2. 在验证集上加入语义 proxy 指标，而不只用 RGB PSNR 选择最优轮次。
3. 加入 prompt ensemble，并在不读取测试标注的前提下校准文本阈值。
4. 为不同 SH 阶数实现分桶 rasterization，才能把“有效阶数”真正转成运行时收益。
