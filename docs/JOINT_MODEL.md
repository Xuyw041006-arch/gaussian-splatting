# Joint Semantic-Adaptive 3DGS

本模型把 RGB 重建、层级语义蒸馏和三级重要性资源分配放进同一次 3DGS
优化。它借鉴 LaGa 的跨视图语义聚合思想，以及 SAGA 的尺度门控和多粒度分割
思想，但当前实现是面向一周 MVP 的工程化组合，不是两者的官方复现。

## 1. 数据流

```text
多视角图像 + COLMAP 相机
           │
           ├─ SAM 多尺度区域 ─ CLIP ViT-H/14 区域描述符
           │                      │
用户/LLM 三级词表                 ├─ 全场景 64 原型聚合（跨视图去噪）
重要 / 普通 / 背景 ───────────────┤
                                  ├─ PCA 32 维层级语义监督
                                  └─ 每视图三级重要性图
                                                │
原始 3DGS RGB loss ─────────────────────────────┤
层级 semantic loss ─────────────────────────────┼─ 同一次 backward
3D 邻域 consistency loss ───────────────────────┤
                                                │
                         重要性控制 split / prune / SH capacity
```

每个高斯除原始位置、协方差、透明度和球谐颜色外，还带有 32 维语义参数
`s_i` 和 `[0,1]` 重要性分数 `q_i`。clone、split、prune 会同步复制或过滤
这两个字段，因此不存在“重建完以后再硬贴语义”的断层。

## 2. 跨视图与多粒度监督

对 SAM 区域 `r`，先计算置信度：

```text
c_r = max(0.05, sqrt(predicted_iou_r * stability_r))
```

将全场景区域 CLIP 特征聚为最多 64 个原型。区域到所属原型的融合权重为：

```text
beta_r = 0.65 * clip(cos(f_r, p_k) * compactness_k * c_r, 0, 1)
f'_r   = normalize((1 - beta_r) * f_r + beta_r * p_k)
```

这会降低单视图 SAM/CLIP 抖动，但它目前是“全局原型一致性”，还没有 LaGa
完整的显式对象图和视图匹配。聚合后的特征以全场景 PCA 压到 32 维。

SAM 区域按占图面积分三层：

- fine：`area < 5%`
- middle：`5% <= area < 25%`
- coarse：`area >= 25%`

训练按 coarse → middle → fine 循环，并通过由尺度输入控制的 sigmoid channel
gate 选择语义通道。每轮渲染 3 个 RGB chunk，即监督 9 个语义维度；chunk
轮换覆盖全部 32 维。渲染结果除以 alpha，避免透明背景把特征幅值压小。

## 3. 三级重要性

区域与用户或 LLM 文本做 CLIP 匹配；相似度阈值为 `0.24`，并为每个提示词
保底选择 top-1 区域。占图超过 `80%` 的大区域不能自动成为普通物体。重要匹配
覆盖普通匹配；未匹配区域作为背景。高斯中心投影到每轮相机后读取三级标签：

- `q < 0.25`：背景
- `0.25 <= q < 0.75`：普通
- `q >= 0.75`：重要

新出现的更高等级证据立即生效；降级证据用 `EMA=0.90` 慢速融合，以免一个
遮挡或错误视角立刻取消用户指定物体的优先级。

## 4. 联合损失

Ramen 配置的总损失为：

```text
L = 0.8 * weighted_L1_rgb
  + 0.2 * (1 - SSIM)
  + 0.20 * weighted_L1_semantic
  + 0.02 * L_3D_neighbor
```

其中 RGB 像素权重和语义像素权重分别为：

| 档位 | RGB | semantic |
|---|---:|---:|
| 背景 | 0.35 | 0.15 |
| 普通 | 1.00 | 1.00 |
| 重要 | 4.00 | 4.00 |

语义误差还乘 SAM 置信度。`L_3D_neighbor` 每 8 轮在 512 个按重要性采样的高斯
上计算最近邻 Smooth-L1，再按 3D 距离指数衰减；实现中乘 8 抵消低频计算。
Ramen 从第 500 轮开启语义，语义参数学习率 `0.01`，gate 学习率 `0.001`。

## 5. 资源分配

原始 3DGS 的 clone/split 逻辑保留，只改变不同档位的触发阈值；基础位置梯度
阈值为 `1.5e-4`，基础 opacity 剪枝阈值为 `0.005`：

| 档位 | split 梯度阈值 | opacity 剪枝阈值 | 有效 SH 阶数 |
|---|---:|---:|---:|
| 背景 | `2.70e-4` | `0.0100` | 1 |
| 普通 | `1.50e-4` | `0.0050` | 3 |
| 重要 | `8.25e-5` | `0.0025` | 5 |

语义渲染产生的屏幕空间梯度也累计进 densification，所以语义边界可以触发
分裂。SH 通过逐高斯梯度 mask 和参数归零实现不同有效阶数。当前 CUDA
rasterizer 仍按场景全局最高五阶执行，因此计算节省主要来自高斯总数减少，
不是完整的稀疏 SH kernel 加速。

## 6. Ramen 测试协议与结论

`scripts/run_ramen_benchmark.py` 使用 131 张训练图、4 张留出相机，其中 3 张
带 LERF-Mask 标注的视图用于语义和局部画质统计。固定文本阈值 0.25，不在测试
标注上调参。pilot 使用 NVIDIA L4、1,500 次 RGB 迭代；顺序基线另做 300 次
语义迭代，联合模型从第 500 轮开始同时训练语义。

真实结果保存在 `benchmarks/ramen_pilot_1500.json`。联合模型用少 44.5% 的
高斯，使重要类别 mIoU 从 10.49% 提升到 12.21%；重要高斯占 44.58%，而
重要监督像素占 22.89%，说明优先密度分配确实发生。另一方面，全局 PSNR
下降 0.99 dB、全局 mIoU 下降 1.16 个百分点、Boundary-IoU 下降 3.21 个百分点。
因此当前证据支持“重点资源分配有效”，不支持“全局质量已经超过现有方法”。

Notebook 的高性价比 full 模式默认使用 15,000/5,000 轮，联合语义从第 1,000
轮开启，densification 在第 10,000 轮结束，最后 5,000 轮用于稳定优化。
需要测量 30k 上限时可显式传入 `--iterations 30000`。论文结论仍应使用相同预算
重跑 SAGA、Gaussian Grouping 等基线。LaGa/SAGA 论文结果只能作为外部参考，
不能和本 pilot 混成同一张公平排名表。

## 7. 下一轮优先优化

1. 用相机位姿和重投影重叠构造对象轨迹，替代仅靠全局 KMeans 的弱跨视图关联。
2. 将 3D 邻域正则改为边缘感知 affinity contrastive loss，避免跨物体边界平滑。
3. 在不读取测试标注的验证集上校准文本阈值，并加入 prompt ensemble。
4. 放宽背景剪枝或设置总高斯预算约束，找回约 1 dB 全局 PSNR。
5. 为不同 SH 阶数实现分桶 rasterization，才能把“有效阶数”真正转成运行时收益。
